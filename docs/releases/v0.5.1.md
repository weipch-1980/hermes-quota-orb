# Quota Orb v0.5.1 - Windows MCP widget autostart

Quota Orb v0.5.1 adds an explicit Windows-only MCP opt-in for the independent desktop widget.

## Highlights

- `python -m quota_orb.mcp_server --transport stdio --autostart-widget` starts the bundled `quota-orb-widget.exe` before the MCP server begins serving.
- Widget startup is fail-closed: unsupported platforms, a missing executable, or a Windows launch error leave the MCP server running without a GUI.
- The widget uses a local Windows named mutex, so repeated MCP launches retain one orb instance.
