# Quota Orb v0.5.0 — Official Codex rate limits and a refined Windows orb

Quota Orb v0.5.0 adds a local, read-only Codex rate-limit source and turns the Windows widget into a responsive crystal-orb dashboard while preserving truth-only quota semantics.

## Highlights

- **Official Codex rate-limit source:** Quota Orb starts the selected Codex executable with the experimental `app-server --stdio` protocol and calls only `account/rateLimits/read`.
- **No credential or REST expansion:** the source sends no credentials, reads no credential files, exposes no independent REST API, and returns `Unavailable` for absent or invalid official data.
- **Percentage-correct crystal liquid:** visible liquid area matches the remaining percentage; two natural asymmetric waves animate independently inside the orb.
- **Clean Windows edge:** the color-key-safe circular frame has no external shadow or alpha fringe.
- **Professional bilingual details:** fixed interface labels support English and Simplified Chinese, while provider, model, source, and quota-window labels remain exactly as returned.
- **Responsive refresh:** one background worker collects snapshots without freezing the UI; a failed refresh keeps the latest verified snapshot visible and reports the failure.
- **Truth-only fallback:** the lowest valid subscription window drives the orb. An explicit Token allowance is considered only when no valid subscription window exists; real 0% and Unknown remain distinct.
- **Fail-closed CI:** every native install, test, syntax-check, build, and release command now throws on a nonzero exit before publication can continue.

## Codex boundary

The Codex app-server protocol is experimental and may change. Quota Orb treats it as a local child-process protocol, not a supported standalone REST service. It never requests passwords, API keys, OAuth tokens, or browser data. Raw quota-window labels are evidence and are not translated.
