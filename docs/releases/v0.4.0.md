# Quota Orb v0.4.0 — Universal, honest quota visibility

Quota Orb v0.4.0 expands the Hermes-native emerald orb into a local-first, read-only quota system for AI coding agents, MCP-compatible clients, and an independent Windows desktop widget.

## Why this release

AI hosts expose different combinations of subscription quota, API allowance, local Token usage, and billing data. Quota Orb deliberately keeps those signals separate instead of manufacturing one misleading “remaining balance.” When an official source is unavailable, the UI says **Unavailable** rather than showing a false zero or inferred percentage.

## Highlights

- **One conservative schema, multiple hosts** — supports Hermes, Codex, Claude Code, Gemini/Antigravity, Cursor, GitHub Copilot, Qwen Code, Kimi CLI, OpenClaw, and WorkBuddy/CodeBuddy Code through their documented Skill/MCP boundaries.
- **Actual versus estimated cost** — provider-reported billed amounts are labeled `actual`; calculations based on a dated official price table are labeled `estimated`; local Token totals are never presented as an invoice.
- **Independent Windows orb** — borderless, always on top, draggable across monitors, DPI-aware, position-persistent, and honest about real 0% versus Unknown.
- **Strict status colors** — `<30%` red, `30%–<50%` yellow, `>=50%` green, while unavailable data remains neutral.
- **Safer portable installation** — the Universal installer requires an explicit target and never falls back to Hermes. OpenClaw uses its official managed global CLI rather than a guessed private directory.
- **Hardened Windows file operations** — installers and release builders reject symlink/junction/reparse escapes and guard check-to-commit paths against parent-directory swaps.
- **Read-only MCP surface** — exactly three MCP tools: `get_quota_snapshot`, `get_daily_usage`, and `get_supported_sources`, with stdio and loopback-only Streamable HTTP transports.
- **Reproducible supply chain** — deterministic Hermes-only and Universal ZIPs, SHA-256 sidecars, CI integrity checks, and separate GitHub Artifact Attestations.

## Which package should I download?

### Recommended for most users: Universal

Download `quota-orb-universal-v0.4.0.zip` if you use Codex, Claude Code, Gemini/Antigravity, Cursor, Copilot, Qwen, Kimi, OpenClaw, WorkBuddy/CodeBuddy, or want the independent Windows widget and shared MCP server.

The Universal installer is preview-first and requires an explicit target. It does not silently install into Hermes.

### Hermes users: Hermes Skill

Download `quota-orb-skill-v0.4.0.zip` only when Hermes is the explicitly selected host. It contains the native Hermes Skill, desktop plugin, and read-only backend assets.

## Privacy and limits

Quota Orb does not scrape webpages, cookies, browser storage, private provider endpoints, or credentials. Personal subscription balances remain **Unavailable** unless an official authorized source reports them. Calling a model API is not treated as proof that the vendor's chat client supports Quota Orb natively.
